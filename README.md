# HvostNetLib

Сетевая библиотека для приложения «Хвост». Библиотека работает с REST API PocketBase и WebSocket-сервером: авторизация, профиль, питомцы, каталог, записи к врачу и события в реальном времени.

## Подключение

Проект содержит библиотеку `netLib`. 

Создание библиотеки:

```kotlin
val netLib = HvostNetLib(
    context = applicationContext,
    baseUrl = "http://10.0.2.2:8090/api/",
    wsUrl = "ws://10.0.2.2:8091/ws"
)
```

- `HvostNetLib` создаёт и настраивает библиотеку.
- `context` используется для работы с Android и хранения токена, 
- `baseUrl` задаёт адрес REST API, а 
- `wsUrl` — адрес WebSocket-соединения для получения событий в реальном времени.
- `10.0.2.2` используется для обращения к локальному серверу с Android-эмулятора.

Для эмулятора Android, используется `10.0.2.2`. Для физического устройства укажите IP компьютера в локальной сети.


## Репозитории

- `authRepository` — регистрация, авторизация, обновление токена и работа с ним.
- `profileRepository` — получение и изменение профиля.
- `catalogRepository` — услуги, клиники и врачи.
- `petRepository` — список, добавление, изменение и удаление питомцев.
- `appointmentsRepository` — слоты, создание, получение и отмена записей.
- `realtimeClient` — WebSocket-подключение, подписки и события.

Токен после авторизации сохраняется внутри библиотеки и автоматически добавляется к REST-запросам. После refreshToken() сохранённый токен заменяется.

## WebSocket

Клиент предоставляет `Flow<WebSocketEvent>`. Поддерживаются события `hello`, `pong`, `error`, `slot_taken`, `slot_freed`, `status`, `delay`, `queue` и ответы на подписки. При обрыве соединения выполняется переподключение с увеличением паузы до 30 секунд.

## Ошибки

Результаты запросов возвращаются через `NetworkResult`:

- `Success` — успешный ответ;
- `Error` — ошибка сервера с HTTP-кодом, сообщением и ошибками полей;
- `NoInternet` — нет сети;
- `Timeout` — превышено время ожидания;
- `SerializationError` — ошибка разбора ответа.

## Используемые библиотеки

- Kotlin и Kotlinx Serialization;
- Kotlin Coroutines;
- Ktor Client 2.3.12 (OkHttp, Content Negotiation, Logging, WebSockets);
- Android SharedPreferences для хранения токена.
